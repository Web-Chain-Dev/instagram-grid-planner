# Instagram Grid Planner

Create a website that is optimized both for mobile and computer use and should be like one of those instagram arranging apps where you can see your instagram page EXACTLY how it looks in instagram, not something similar, but exact. The the user must be able to upload, delete, rearrange photos, reels, story highlights, pinned, etc in the grid and it must look like a 1-1 copy of their instagram. It must have a login and be connected to a db so the user doesnt lose their progress, and the migration code should also be ready just in case for the db. Out of the box it should have all that functionality and also it should have the option to connect an existing account to pull their grid from the app and work from there
